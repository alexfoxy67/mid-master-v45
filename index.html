5. Notas y evidencia

Esta primera versión calcula la distribución de marcadores con Poisson independiente. No implementa aún una API deportiva ni estima automáticamente módulos cualitativos a partir de noticias. Esos módulos requieren datos verificados y una capa de ingestión real.

Historial guardado en este dispositivo

Auditoría postpartido

Selecciona un partido guardado y registra el marcador real. La auditoría compara probabilidades previas con resultado observado; no altera el modelo automáticamente.

Fuentes y límites

SIN CONEXIÓN API ACTIVA

La aplicación no descarga datos deportivos automáticamente en esta versión. Para habilitarlo, hace falta elegir un proveedor de fixtures/estadísticas y configurar una API o backend seguro. No se incluye una clave inventada ni se raspa Score365.

Importar partidos

Puedes importar el historial exportado en JSON. La importación no convierte datos sin verificar en datos oficiales.
